# Java Design Patterns Repository

A clean and educational collection of Gang of Four (GoF) design pattern implementations in Java. Each pattern is structured as a self-contained mini-project demonstrating core mechanics and architecture.

### Implemented Patterns:
- **Singleton**: Scheduler
- **Facade**: Computer boot process coordination
- **Strategy**: Text processing system with interchangeable algorithms
- **Template Method**: Beverage preparation with algorithm skeletons and hooks
- **Factory Method**: Logistics transport creator
- **Prototype**: Object cloning via copy constructors
- **Command**: Smart home device toggling via remote control
- **Adapter**: Weather sensor unit conversion bridging legacy and modern interfaces
- **Decorator**: Cloud server functionality extension using wrapper layers
- **Observer**: Server status monitoring and alert notifications
- **Proxy**: Access-controlled server connection with lazy loading
- **Builder**: Cloud server construction via a director and specific builders
- **Abstract Factory**: Multi-cloud component family creation (AWS vs Azure)
- **Mediator**: Centralized system control and inter-component communication
- **Memento**: Cloud server configuration state backup and rollback (undo)
- **Bridge**: Decoupling cloud server abstractions from low-level platform implementations
- **Flyweight**: Memory optimization via shared server configuration caching
